Trip Receipts

Your phone's payments, on any screen

The Trip Receipts app catches every payment SMS on the iPhone. With website sync on, it writes them to a private GitHub repo after each change, and this page reads them from there. No server sits in between.

  1. Phone: Trip Receipts → Setup → Website. Enter the owner, the private repo and a token with Contents: Read and write on that repo only, then tap Save and sync now.
  2. Here: enter the same repo and a second token with Contents: Read-only. Create a fine-grained token ↗

The token stays in this browser and is only ever sent to api.github.com. This page is static files on GitHub Pages.
